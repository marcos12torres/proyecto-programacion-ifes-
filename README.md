## Descripción

El sistema permite administrar pacientes, médicos y turnos médicos.

Se podrán registrar turnos de distintos tipos (consulta, estudio y cirugía), gestionar pacientes y médicos, controlar el estado de los turnos y realizar consultas sobre la agenda utilizando los conceptos vistos en la materia.

## Funcionalidades

* Registrar pacientes.
* Registrar médicos.
* Agregar turnos.
* Confirmar turnos.
* Cancelar turnos.
* Mostrar turnos pendientes.
* Mostrar agenda ordenada por fecha.
* Mostrar cantidad de turnos cancelados.
